# 人文组 · 拼贴诗工作台

清华大学电子工程系团委人文组的社团主页（BBS 用），包含 **组织介绍** 与 **拼贴诗生成器** 两部分。

## 一句话说明

- **组织介绍**：组织定位与日常工作，以及清锋明辩、社区共读、学生节舞台剧三项活动介绍。
- **造词机**：**四个同构的列表**，每个列表里都是「子分类（点一下勾选）+ 造词按钮 + 结果区」：
  - **短语**：10 种句法结构（偏正 / 主谓 / 动宾 / 联合 / 动补 / 的字短语 / 数量短语 / 把字兼语 / 时间状语 / 关联结构）× 555 个词的词库。
  - **句子**：论述整句、见闻陈述、抽象长句、诗性句、短句断句、名句成句（每条带出处）。要的就是「熟悉又莫名」的整句感。
  - **词汇**：论述术语、抽象定语、抽象副词、抽象谓语、连接词、意象词（105 个高频意象）。
  - **自定义输入**：自己写的词句，一行一条，存在浏览器里；可勾选「按空格 / 标点拆成短词」再取。
- **背景模板**：17 套纸 —— 纯色 / 横线 / 竖线 / 方格 / 稿纸 / 点阵 / 信纸 / 牛皮纸 / 报纸 / 试卷 / 米白 / 布纹 / 旧纸 / 乐谱 / 日历 / 复写纸 / 深色纸，一键随机。
  纸纹是**可无缝平铺**的，尺寸用固定像素（不是 `cover`），所以换模板、换窗口大小、切到手机正方形版式，纸的粗细都不会变；弹窗里还有「纸纹粗细」可调，底板与贴纸一起变。
- **贴画质感**：每张纸片可单独调
  - **纸感**（8 种：纸纹 / 褶皱 / 旧纸 / 报纸 / 试卷 / 牛皮 / 复写 / 光面）
  - **褶皱**（纤维颗粒 + 两层交叉折痕光照贴图，强度越高折痕越密越明显）
  - **墨感**（印刷的墨水凹凸：浅色高光在字下面错位一点点）
  - **用量**（缺墨浓淡：用一张"缺墨"蒙版啃掉字的边缘，做出印刷没吃上墨的斑驳）
  - 另有「🎲 随机质感」（9 套预设）和「应用到全部」。
- **电子拼贴**：碎片拖拽、旋转、缩放、胶带、撕口纸边；双击改字。
- **剪字**：上传任何带文字的图片（杂志页、海报、截图），页面自动框出文字位置，把字**抠出来**（纸底透明）做成碎片。
- **导出**：一键导出 1×/2×/3× 的 PNG，可加标题、去落款、透明背景、做旧调色。**屏幕上看到的纸纹与墨迹会一起进导出图**（同一套绘制函数画两遍）。

## 怎么改

### 1. 改组织介绍文案（最常改）

打开 `src/index.html`，修改“关于我们”板块中的组织定位、基本情况与活动介绍。

当前介绍根据[团委招新推送](https://mp.weixin.qq.com/s/lAvghKOfiKucDSbl3k2bgA)中“人文组”相关内容整理，涵盖人文讲座、读书沙龙、同窗交流，以及清锋明辩备赛、社区共读和学生节舞台剧。更新时请核实来源；人数、联系方式和具体年份的赛事成绩应确认后再补充。

改完重新打包（见下）。

### 2. 改词库

打开 `src/script.js`，找到 `const BANK = {`：

```js
noun: [ '月亮', '黄昏', ... ],   // 名词（可以重复写，写几次权重就高几倍）
adj:  [ ... ],                   // 形容词
vt:   [ ... ],                   // 及物动词（能带宾语）
vi:   [ ... ],                   // 不及物动词（人做主语）
ni:   [ ... ],                   // 事物 / 自然类动词
attrib: [ '迷路', '过期', ... ],  // 只能修饰名词的词
comp: [ ... ],                   // 动补结构的结果补语
```

新词加进去就行，造词引擎会自动用上。想强调某个意象（比如"月亮"），
在 `WEIGHT` 里给它一个更大的数字即可。

### 3. 改句法结构

同一文件里的 `const STRUCTS = [...]`。每个结构长这样：

```js
{
  key: 'modifier', name: '偏正短语', hint: '青草池塘处处蛙',
  desc: '面板上显示的结构说明',
  templates: ['形容词+的+名词', '名词+的+名词', ...]
}
```

模板用 `+` 连接"槽位"，槽位可以是：

- 词类名：`名词` `形容词` `动词` `副词` `代词` `指示` `量词` `时间` `处所` `颜色` `补语` `名词短语` `的字结构` `并列` `连接`
- 固定字面：`的` `得` `成` `满` `了` `与` `和` `一场` `这个` 等
- `X`：一个占位定语（会填一个能修饰名词的词）

加一行模板就等于加一种造句方式。

### 4. 改语料库（四个列表的内容）

打开 `src/corpus.js`：

- **一句话看懂结构**：每个「子分类」就是一个池子（pool），池子用 `group` 字段归到某个列表：
  - `group: 'sentence'` → **句子**列表
  - `group: 'vocab'` → **词汇**列表
  - 不写 group 的（名句 / 论述摘句 / 论述术语 / 论述句式）会自动并进句子或词汇列表
- **加名句**：往 `QUOTES` 里加 `{ t: '句子', s: '出处' }`。太长的会自动排除在「名句成句」之外。
- **加子分类**：在 `POOLS` 里加一项：

  ```js
  { id: 'myPool', name: '我的分类', kind: 'fixed', group: 'vocab',
    hint: '角标里显示的小字', desc: '说明',
    items: ['词一', '词二'] }        // fixed：给现成条目
  ```

  或者用生成式：

  ```js
  { id: 'myGen', name: '我的生成器', kind: 'gen', group: 'sentence',
    hint: '每次现造', count: 24,
    make: (seed) => 你的生成函数(seed) }
  ```
- **加句子模板**：`ESSAY` 里是各槽位（`frame` 句首框架、`link` 连接、`noun` 抽象名词、`pred` 抽象动词、`open/arg/close` 句式模板），
  模板里用 `{X} {Y} {Z}` 占位名词、`{PRED}` 占位动词。整句生成器是 `makeSentence(kind, seed)`，
  kind 取 `frame / seen / abstract / poetic / shortcut / quote`。想加新类型，在 `makeSentence` 的 `switch` 里加一个 case，
  再在 `POOLS` 里加一个 `group: 'sentence'` 的 gen 池指过去。

改完跑 `node test/corpus-test.js 40` 看有没有出问题。

### 5. 改背景模板与纸纹

`src/paper.js`：

- `BG_TEMPLATES`：每套模板给 `paper`（底色）、`textures`（用哪种纸纹）、`line`（线条类型与参数）。线条类型支持
  `h` 横线、`v` 竖线、`grid` 方格、`dots` 点阵、`letter` 信纸、`music` 五线谱、`news` 报纸、`exam` 试卷、`calendar` 日历。
- `TEX_CFG`：纸纹参数（`fbmAt` 控制褶皱疏密、`relief` 控制起伏强度、`base` 控制底色深浅）。想调褶皱的"大块/细密"，改 `fbmAt`。
- 新增纸纹只要在 `TEX_CFG` 与 `TEXTURE_LIST` 里各加一项。

### 6. 改质感预设

`src/script.js` 里的 `FX_PRESETS`（干净 / 试卷 / 报纸 / 旧纸 / 揉皱了 / 牛皮纸 / 复写纸 / 墨迹重 / 干净纸纹）。
每项是 `{ name, tex, fold, ink, palette }`，`tex` 取 `FX_TEX` 里的 key。加一项就多一个随机质感。

## 自检

```bash
node test/engine-test.js 20    # 造词引擎：20 条/结构，查词类名泄漏、叠字、搭配、长度
node test/corpus-test.js 40    # 语料库：40 条论述句，查连词叠用、标点、长度、占位符残留
node test/tex-calibrate.js     # 纸纹：量每种纸纹的亮度起伏（标准差 < 1.5 就是没画出来）
node test/export-verify.js     # 导出：跑一遍导出绘制，量像素并生成 test/export-preview-*.png
```

后两个是**纯 Node 的**，不需要浏览器——这样验证纸纹与导出路径既不占资源，也不会去碰你正在用的浏览器。

浏览器端全流程自检：先 `node tools/serve.js 8787`，再打开
`http://127.0.0.1:8787/test/test.html`，页面底部会输出一份 JSON 体检报告。

> 提示：无头浏览器跑这种带大量 canvas 与纸纹生成的页面很吃资源，建议一次只开一个，
> 跑完记得关掉，否则容易把机器拖慢。（宁可优先用上面两个 Node 版验证。）

## 视觉规范（改配色前先看这里）

配色方法参考了 GitHub 上的 **[awesome-claude-design](https://github.com/rohitg00/awesome-claude-design)**（按美学流派分组的 DESIGN.md），
采用其中的 **warm editorial（暖色编辑风）** 骨架，并结合社团身份做了取舍。

### 颜色 token（`src/styles.css` 的 `:root`）

| 用途 | 变量 | 值 | 对比度（对奶油底） |
| --- | --- | --- | --- |
| 页面底 | `--paper` | `#f4f3ee` | — |
| 抬升面 | `--paper-2` | `#eeede6` | — |
| 正文 | `--ink` | `#191817` | 15.96:1 AAA |
| 次级文字 | `--ink-soft` | `#5a554e` | 6.65:1 AA |
| 弱化文字 | `--ink-faint` | `#8a847a` | 3.34:1（仅用于标签） |
| **强调色** | `--accent` | `#b1502f` 陶土 | 4.66:1 AA |
| 强调 hover | `--accent-hi` | `#98442a` | 5.92:1 AA |
| 识别色 | `--thu` | `#6f2c91` 清华紫 | 7.73:1 AAA |
| 细线 | `--line` | `#d8d3c8` | — |

### 硬规矩（踩过的坑）

1. **清华紫只作识别色**：目前只出现在三处 —— 徽标底部那条 3px 线、导航选中的下划线、底板色块选中环。
   **不要**再拿它铺按钮、做主色或做渐变（原先紫色渐变按钮是"显丑"的主因）。
2. **强调色一个视口只用一处**：现在是"导出 PNG"按钮与重点词下划线。陶土色不与自己竞争。
3. **禁止渐变按钮、禁止悬浮抬起**。悬浮只换底色或边线颜色。阴影只给真的浮起来的东西
   （弹窗、拼贴碎片、胶带），普通卡片一律 1px 细线 + 底色差。
4. **层次靠字号和留白**，不靠阴影和圆角。圆角基准是 4–8px，不用胶囊（导航除外，已改下划线）。
5. **正文字号保持 14.5–15.5px、行高 1.65–1.75**；标题用衬线，UI 用无衬线，全页只两种字体族。
6. **皮肤噪点层不透明度 ≤ 0.3**，否则整页发灰。

改完配色请跑一次对比度自查（正文/次级/强调对底色都应 ≥ 4.5:1）。

## 技术说明（为什么导出能和屏幕一致）

纸纹与线条都用**同一套程序生成**，两条路径共用：

- 屏幕侧：把纸纹当 DOM 背景铺，配 `background-blend-mode: multiply` / `mix-blend-mode`；
- 导出侧：同一张 canvas 纹理走 `createPattern` + `globalCompositeOperation = 'multiply'`，
  线条则调用同一个 `PaperLab.drawLines()`。

所以不存在"屏幕上好看、导出变平"的问题。墨迹凹凸同理：屏幕用两层错位的文字（浅色高光
`screen` + 深色本体 `multiply`），导出用同样两层错位的 `fillText` 加噪声缺墨蒙版。

**纸纹的自标定**：Perlin 噪声在不同频率下的绝对幅度差很多，直接乘一个固定系数会导致
"要么纯白、要么全黑"。所以 `makeTexture()` 会先采样一遍高度场，量出标准差并归一化，
这样 `TEX_CFG` 里的 `relief` 就是**起伏的灰阶幅度（±）**，改参数的效果可预期。
另外 `base` 必须留出余量：`base + relief` 一旦超过 255 就会被截断成纯白（踩过这个坑）。
改纸纹后请跑 `node test/tex-calibrate.js` 确认标准差 ≥ 1.5。

**纸张尺寸不能用 `cover`**：`.board__paper` / `.board__tex` 的 `background-size` 必须是固定像素。
用 `cover` 会按容器比例缩放，同一个纹理在 4:3 与手机 1:1 版式下大小不同，看起来就"不对版"。

**墨感的两个要素**：① 浅色高光层画在字**下面**、只错位一点点（做出压印）；② 缺墨用专门的
「缺墨」蒙版（中灰底 + 细密亮点，见 `TEX_CFG.worn`）叠在字**上面**，只啃边缘。
早先用纤维纹当蒙版、又把字设成 `multiply`，结果是把字整块洗成灰色 —— 别再走这条路。

## URL 参数（做 BBS 链接很方便）

| 参数 | 作用 |
| --- | --- |
| `#studio` `#assets` `#help` `#intro` | 直接打开对应板块，例如 `...html#studio` |
| `?tpl=news` | 直接指定背景模板（`plain` `line` `grid` `manuscript` `letter` `kraft` `news` `exam` `aged` `music` `calendar` `dots` …） |
| `?demo=1` | 自动装一份示例（随机一首诗 + 样张剪下的字），用于演示 / 截图 |
| `?demo=1&crop=1` | 演示时装好碎片但停在"识别到的文字"弹窗，方便讲剪字功能 |
| `?reset=1` | 忽略浏览器里的本地草稿，从空板开始 |

## 数据与隐私

- 上传的图片**只在浏览器本地处理**，不会上传到任何服务器（页面本身也没有后端）。
- 拼贴进度自动存在本机浏览器（localStorage），关掉再打开还在；换设备不会同步。
- 剪下的碎片素材请使用自己拍摄、自己制作或已获授权的图片；成品建议仅用于个人欣赏与非商业展示。

## 兼容性

Chrome / Edge / Safari / Firefox 现代版本均可；手机浏览器可用（板子会变成正方形，工具条自动缩放）。
不需要联网，不需要构建工具，双击单文件 HTML 即可运行。
