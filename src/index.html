一句话定位

人文组是电子系团委的文字与视觉输出中枢：团委的大事小情，先由我们写成能读的文字， 再由我们做成好看的图。我们既写会议纪要、活动预告、人物专访，也做海报、推送排版和 舞台背景；既在键盘前改第 7 版标题，也在深夜的打印店门口等一块展板。

我们做的事情听起来不「电子」，但恰恰是电子系最缺的一块：把技术语言翻译成人话， 把一次活动翻译成一段记忆。工科的严谨 + 文科的表达，这是我们想守住的结合点。

「我们不改电路，
我们改稿。」

TIP

剪字小经验

什么图最好剪

  • 字大、笔画粗：海报标题、书封、杂志大标题
  • 背景干净：白纸、纯色底、天空
  • 对比度强：黑字白底最稳

剪不干净怎么办

  • 拖动「识别阈值」，直到方框刚好框住字
  • 深底浅字记得把模式切成「浅字深底」
  • 在预览图上点方框可以取消不要的那几个

使用提醒

  • 导入的图片只在浏览器本地处理
  • 请使用自己拍摄、自己制作或已获授权的素材
  • 拼贴成品建议仅用于个人欣赏与非商业展示
How to play

玩法说明

三步做一张拼贴诗：造词 → 剪字 → 拼贴导出。没有灵感的时候，直接按「随机拼一首」。

① 造词机

  • 四个列表：短语（10 种句法）· 句子（论述整句 / 见闻 / 抽象长句 / 诗性句 / 短句 / 名句）· 词汇（术语 / 定语 / 副词 / 谓语 / 连接词 / 意象词）· 自定义
  • 每个列表里点「子分类」勾选，再点「造词」——一次出 5 条随机样例
  • 按 R 也能造词（用「短语」列表）
  • ⧉ 复制文字（粘到别处）· ↘ 贴到板子上 · ❞ 连出处一起贴 · ≡ 一次复制全部
  • 造过的词句会自动进下面的「最近造过的词句」，随时点回来用（只存当前页面，刷新即清空）

② 剪字

  • 上传带文字的图片，自动框出文字块
  • 点方框可取消 / 选中，再点「剪下选中的文字」
  • 碎片进入「碎片篮」，点一下就贴到板上
  • 内置样张可以直接体验全流程

③ 拼贴

  • 拖动碎片；右下角小方块拖拽可缩放
  • 选中后弹出工具条：角度、大小、胶带、字体、纸色、层级
  • ⎘ 再贴一片（内容一样、位置和角度错开），用来做叠印效果
  • 双击文字碎片可以直接改字
  • 底板可切换黑板 / 牛皮纸 / 米白纸 / 方格纸

快捷键

  • Ctrl+Z 撤销 · Ctrl+Shift+Z 重做
  • Del 删除选中 · D 复制一片
  • [ ] 旋转 · 方向键微调（Shift 加速）
  • Esc 取消选中

导出

  • 「导出 PNG」可选 1×/2×/3× 分辨率
  • 可加标题、去掉落款、透明背景
  • 「做旧调色」会整体压一层旧纸色，更像实物

关于草稿

  • 拼贴内容会自动存在本机浏览器里，关掉再打开还在
  • 「清空」后按 Ctrl+Z 还能救回来
  • 换电脑 / 换浏览器不会同步
