02 / ACTIVITIES

我们做什么

A

清锋明辩赛事

“清锋明辩”是清华大学的全校性大型辩论文化节。人文组组织电子系参赛队伍备赛，参与人员选拔与阵容组建，打磨立论、驳论和论据，并通过模拟辩论及与其他院系队伍的实战交流，不断调整战术、锻炼思辨与表达能力。

队伍组建论据打磨模拟辩论
B

社区共读活动

我们定期走进社区，与社区建立稳定合作，对接儿童阅读需求。成员按孩子的年龄与认知水平挑选经典绘本、童话和科普故事，设计共读材料与互动问题卡；面向全校招募并培训志愿者，在共读、问答与陪伴中激发孩子的思考和表达，让阅读的种子生根。

材料设计志愿培训阅读陪伴
C

学生节舞台剧

每年电子系学生节，人文组由组长执笔撰写舞台剧剧本，组员全员参与排演。我们把电子人的日常、青春困惑与理想情怀写进剧情，承担表演、场务与道具等工作，利用课余时间磨合台词和走位。从写故事到演故事，一起在舞台上创造属于电子系的高光时刻。

剧本创作全员排演舞台协作

TIP

剪字小经验

什么图最好剪

  • 字大、笔画粗：海报标题、书封、杂志大标题
  • 背景干净：白纸、纯色底、天空
  • 对比度强：黑字白底最稳

剪不干净怎么办

  • 拖动「识别阈值」，直到方框刚好框住字
  • 深底浅字记得把模式切成「浅字深底」
  • 在预览图上点方框可以取消不要的那几个

使用提醒

  • 导入的图片只在浏览器本地处理
  • 请使用自己拍摄、自己制作或已获授权的素材
  • 拼贴成品建议仅用于个人欣赏与非商业展示
How to play

玩法说明

三步做一张拼贴诗：造词 → 剪字 → 拼贴导出。没有灵感的时候，直接按「随机拼一首」。

① 造词机

  • 四个列表：短语（10 种句法）· 句子（论述整句 / 见闻 / 抽象长句 / 诗性句 / 短句 / 名句）· 词汇（术语 / 定语 / 副词 / 谓语 / 连接词 / 意象词）· 自定义
  • 每个列表里点「子分类」勾选，再点「造词」——一次出 5 条随机样例
  • 按 R 也能造词（用「短语」列表）
  • ⧉ 复制文字（粘到别处）· ↘ 贴到板子上 · ❞ 连出处一起贴 · ≡ 一次复制全部
  • 造过的词句会自动进下面的「最近造过的词句」，随时点回来用（只存当前页面，刷新即清空）

② 剪字

  • 上传带文字的图片，自动框出文字块
  • 点方框可取消 / 选中，再点「剪下选中的文字」
  • 碎片进入「碎片篮」，点一下就贴到板上
  • 内置样张可以直接体验全流程

③ 拼贴

  • 拖动碎片；右下角小方块拖拽可缩放
  • 选中后弹出工具条：角度、大小、胶带、字体、纸色、层级
  • ⎘ 再贴一片（内容一样、位置和角度错开），用来做叠印效果
  • 双击文字碎片可以直接改字
  • 底板可切换黑板 / 牛皮纸 / 米白纸 / 方格纸

快捷键

  • Ctrl+Z 撤销 · Ctrl+Shift+Z 重做
  • Del 删除选中 · D 复制一片
  • [ ] 旋转 · 方向键微调（Shift 加速）
  • Esc 取消选中

导出

  • 「导出 PNG」可选 1×/2×/3× 分辨率
  • 可加标题、去掉落款、透明背景
  • 「做旧调色」会整体压一层旧纸色，更像实物

关于草稿

  • 拼贴内容会自动存在本机浏览器里，关掉再打开还在
  • 「清空」后按 Ctrl+Z 还能救回来
  • 换电脑 / 换浏览器不会同步
